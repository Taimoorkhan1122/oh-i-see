# Security Policy

## Supported versions

Only the latest version on the `main` branch is supported with security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use [GitHub's private vulnerability reporting](https://github.com/Taimoorkhan1122/oh-i-see/security/advisories/new) when available. If it is unavailable, contact the repository owner through their GitHub profile and include:

- A description of the vulnerability and its impact.
- The affected version, file, and steps to reproduce.
- A minimal proof of concept, if safe to share.
- Any suggested mitigation.

Please allow reasonable time for investigation and remediation before public
disclosure. Do not include secrets or personal data in the report.
